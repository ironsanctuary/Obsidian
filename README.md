# Obsidian Vault

This repository is a Git-synced [Obsidian](https://obsidian.md) vault. Uploaded source files are converted into linked Markdown notes.

## Structure

- `Notes/` — indexed notes, one per source document
- `Attachments/` — original files and embedded media (PDFs, images, etc.)
- `Index/` — Maps of Content (MOCs) that link related notes together
- `Index/Home.md` — start here

## Using it in Obsidian

1. In Obsidian, install the **Obsidian Git** community plugin.
2. Clone this repo as (or into) your vault folder.
3. Pull to receive newly indexed notes.
