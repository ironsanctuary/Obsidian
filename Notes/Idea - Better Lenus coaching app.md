# Idea: A better Lenus coaching app

Build a coaching app that does what the Lenus client app does, but better.

## Starting points
- Write down what annoys me and my clients about Lenus today.
- Use REA on the Lenus web or Android app to see *how* features work, not to copy code.

## Ways to simplify
- Build on Lenus first: fix the biggest gap with an add-on or my own tools.
- Try existing alternatives (Trainerize, Everfit, TrueCoach) before building.
- Start with one feature clients love, not a full platform.

## Ways to delegate
- Hire a developer or agency to build it from my feature list.
- Use a no-code builder for a first version.

## Open questions
- Do I have capacity for this right now?
- What would I drop to make room?
